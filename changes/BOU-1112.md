### Fixed

- **On `:db`, `delete-job!` left the job pending in `job_store` for good** (BOU-1112); no retention removed it. It
  now deletes a waiting job's store row too, as `:memory` and `:redis` do. See Upgrading for rows left before.

## Upgrading

### Remove jobs deleted before this release (BOU-1112)

Under `:provider :db`, each job deleted before this release left a pending `job_store` row no queue holds and no
retention removes. Delete them once, with the workers stopped so no retry is half-written:

```sql
DELETE FROM job_store
 WHERE status NOT IN ('running', 'completed', 'failed', 'cancelled') AND dead_letter = FALSE
   AND NOT EXISTS (SELECT 1 FROM job_queue q WHERE q.id = job_store.id);
```
