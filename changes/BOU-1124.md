### Fixed

- **On MySQL, search matched tenant ids ignoring case and accents, so `acme` and `ACME` shared documents** (BOU-1124).
  A migration gives `search_documents.filters` a binary collation; every filter value now compares exactly, as on the other engines.
- **A search document indexed with no tenant replaced a tenant's document of the same entity id and cleared its tenant**
  (BOU-1124). It now throws a `:conflict`, as indexing over another tenant's document does.
