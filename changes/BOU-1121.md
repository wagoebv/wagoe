### Fixed

- **Indexing a search document no longer moves another tenant's document to the caller's tenant** (BOU-1121): it
  throws a `:conflict` (409). A custom `ISearchStore` must refuse it too.
- **To move an entity to another tenant, call `remove-tenant-document!` first** (BOU-1121). A blank or collection
  `:tenant-id` filter value is now a `:validation-error`.
