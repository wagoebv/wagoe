[[_request]]
===== link:#_request[]Request

*Method:* `++[++GET++|++POST++|++PUT++|++DELETE++]++` *Path:* `/api/v1/++[++resource++][++/++{++id}++]++` *Content-Type:* `application/json`

*Path Parameters:*

[width="100%",cols="20%,20%,60%",options="header",]
|===
|Parameter |Type |Description
|id |UUID |++[++Description of path parameter++]++
|===

*Query Parameters:*

[width="99%",cols="18%,16%,16%,50%",options="header",]
|===
|Parameter |Type |Required |Description
|limit |integer |No |Maximum number of results (default: 20, max: 100)
|offset |integer |No |Number of results to skip (default: 0)
|===

*Request Body Schema:*

[source,highlightjs,highlight]
----
{:example/field [:string {:min 1 :max 100}]
 :example/id    :uuid
 :example/flag  :boolean}
----

*Example Request:*

[source,highlightjs,highlight]
----
{
  "example-field": "value",
  "example-id": "123e4567-e89b-12d3-a456-426614174000",
  "example-flag": true
}
----

[[_response]]
===== link:#_response[]Response

*Success Status:* `++[++200++|++201++|++204++]++` *Content-Type:* `application/json`

*Response Schema:*

[source,highlightjs,highlight]
----
{:data [:map
        {:example/id :uuid
         :example/field :string}]
 :meta [:map
        {:total :int
         :limit :int
         :offset :int}]}
----

*Example Response:*

[source,highlightjs,highlight]
----
{
  "data": {
    "example-id": "123e4567-e89b-12d3-a456-426614174000",
    "example-field": "value"
  },
  "meta": {
    "total": 1,
    "limit": 20,
    "offset": 0
  }
}
----

[[_error_responses]]
===== link:#_error_responses[]Error Responses

*Status Codes:* ++*++ `400 Bad Request` - Invalid input or validation errors ++*++ `401 Unauthorized` - Authentication required ++*++ `403 Forbidden` - Insufficient permissions ++*++ `404 Not Found` - Resource not found ++*++ `409 Conflict` - Resource conflict ++*++ `500 Internal Server Error` - Unexpected error

*Error Response Format:*

[source,highlightjs,highlight]
----
{
  "error": {
    "type": "validation-error",
    "message": "One or more fields failed validation",
    "details": {"errors": [{"field": "email", "message": "Email format is invalid"}]},
    "correlation-id": "..."
  }
}
----

`type` is the thrown `ex-info`'s `:type`; `details` is optional (`wagoe.platform.core.http.errors`).
