== Wagoe Framework Documentation

Developer-facing documentation: architecture decisions, references and
working notes. It is the counterpart to the published documentation under
`docs/modules/`, which is the Antora source for https://wagoe.org.

[NOTE]
====
*Where to look first.* Architecture guides, getting-started material and the
per-library documentation live in `docs/modules/` and are published on
https://wagoe.org. This index covers `dev-docs/` only — the material that stays
in the repository.

This page previously indexed an `architecture/`, `guides/` and `change-reports/`
tree that was removed when the documentation moved to Antora. Fifty-two of its
links pointed at files that no longer existed. `bb check-links` now reads
AsciiDoc as well as Markdown, so a link that does not resolve fails the build
rather than sitting here.
====
