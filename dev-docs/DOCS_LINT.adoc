= Documentation Lint Tool

The Wagoe repository includes a documentation linter that detects drift between docs and the current monorepo structure.

== What It Checks

[cols="1,2"]
|===
|Check |Description

|`broken-link`
|Internal links (markdown/asciidoc) that point to non-existent files

|`stale-path`
|References to pre-library-split paths (e.g., `src/wagoe/user/` instead of `libs/user/src/wagoe/user/`)

|`unknown-namespace`
|`wagoe.*` namespace references that match no namespace in the repository's source

|`unknown-alias`
|A documented `clojure -M:…` command naming a deps.edn alias that does not exist. Fails the run.

|`ticket-ref`
|A private tracker id (`BOU-123`) on a page under `docs/modules/`, which the public site renders. Fails the run.
|===

== Running Locally

=== Prerequisites

* https://babashka.org/[Babashka] installed

=== Run the Linter

[source,bash]
----
bb docs:lint
# or
bb scripts/docs_lint.clj
----

Both run the implementation in `dev/wagoe/tools/docs_lint.clj`; CI runs the same one with `clojure -M:docs-lint`.

=== Verbose Mode

[source,bash]
----
bb scripts/docs_lint.clj --verbose
----

=== Custom Output Directory

[source,bash]
----
bb scripts/docs_lint.clj --out-dir my-output
----

== Output

The linter generates two reports in `build/docs-lint/`:

* `report.edn` - Machine-readable structured report
* `report.txt` - Human-readable summary

== CI Integration

The `docs-lint` job in `.github/workflows/ci.yml` runs it on every push and pull request and uploads the reports as artifacts.

It fails on `unknown-alias` and `ticket-ref`. Every other finding is a warning.

== Interpreting Warnings

=== `broken-link`

A link in the documentation points to a file that doesn't exist.

**Fix:** Update the link path or create the missing file.

=== `stale-path`

Documentation references old paths from before the library split.

**Example:**
----
src/wagoe/user/core/user.clj
----

**Should be:**
----
libs/user/src/wagoe/user/core/user.clj
----

**Reference:** See link:adr/ADR-001-library-split.adoc[Library Split Migration Guide]

=== `unknown-namespace`

A `wagoe.*` reference is neither a namespace declared in the repository's Clojure source nor a prefix of one.

**Fix:** Use the namespace's current name, or drop the reference if the namespace is gone.

=== `unknown-alias`

**Fix:** Fix the command, or add the alias to `deps.edn`.

=== `ticket-ref`

**Fix:** Cite the pull request instead; GitHub resolves it for readers.

== Known Limitations

* Does not validate external URLs (only internal links)
* Does not check if referenced wagoe repo files actually exist (only validates path patterns)
* Some false positives may occur in example/template documentation
