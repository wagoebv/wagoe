=== Babashka Developer Tooling

The `libs/tools/` directory provides BB-based developer tools invoked via `bb.edn` tasks.
See link:../libs/tools/AGENTS.md[libs/tools/AGENTS.md] for the full reference.

Key tools:

* `bb doctor` — Validate config for common mistakes
* `bb setup` — Interactive config setup wizard (with optional AI mode)
* `bb scaffold integrate <module>` — Write a scaffolded module's config key into config.edn
* `bb ai admin-entity <description>` — Generate admin entity EDN config via AI
* `bb deploy` — Deploy libraries to Clojars
* `bb create-admin` — Create first admin user
* `bb test:tools` — Run wagoe-tools unit tests
