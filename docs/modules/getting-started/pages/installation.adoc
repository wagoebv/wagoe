= Installation
:description: Prerequisites and installation instructions for Wagoe Framework.

== One-liner install (recommended)

The Wagoe installer handles all prerequisites automatically:

[source,bash]
----
curl -fsSL https://get.wagoe.org | bash
----

Fallback if `get.wagoe.org` is unavailable:

[source,bash]
----
curl -fsSL https://raw.githubusercontent.com/wagoebv/wagoe/main/scripts/install.sh | bash
----

Supports macOS, Debian/Ubuntu, Fedora/RHEL, Arch Linux, and WSL2.

=== Verify before you run it

Each release attaches the installer and its SHA-256. Download both, check, then run:

[source,bash]
----
curl -fsSLO https://github.com/wagoebv/wagoe/releases/latest/download/install.sh
curl -fsSLO https://github.com/wagoebv/wagoe/releases/latest/download/install.sh.sha256
sha256sum -c install.sh.sha256    # macOS: shasum -a 256 -c install.sh.sha256
bash install.sh
----

The installer pins the Clojure CLI, Babashka and bbin installers to a release and
checks each, and the Babashka binary on Linux, against a SHA-256 it carries. Not
checked: the Homebrew (macOS) and SDKMAN! (JDK) installers, which publish no
checksum to pin.

After installation, proceed to xref:getting-started:quickstart.adoc[Quickstart].

== Manual installation

Install Java 21+, the Clojure CLI, and Babashka (`bb`) manually if you prefer not to use the installer.

If you already have those installed, skip to xref:getting-started:quickstart.adoc[Quickstart].

=== macOS

[source,bash]
----
brew install openjdk@21 clojure/tools/clojure borkdude/brew/babashka
----

=== Linux (Debian/Ubuntu)

[source,bash]
----
sudo apt-get update
sudo apt-get install -y openjdk-21-jdk curl tar

curl -L -O https://github.com/clojure/brew-install/releases/latest/download/linux-install.sh
chmod +x linux-install.sh && sudo ./linux-install.sh

bash < <(curl -s https://raw.githubusercontent.com/babashka/babashka/master/install)
----

=== Linux (RHEL/Fedora)

[source,bash]
----
sudo dnf install -y java-21-openjdk java-21-openjdk-devel
curl -L -O https://github.com/clojure/brew-install/releases/latest/download/linux-install.sh
chmod +x linux-install.sh && sudo ./linux-install.sh
bash < <(curl -s https://raw.githubusercontent.com/babashka/babashka/master/install)
----

=== Windows (PowerShell + Scoop)

[source,powershell]
----
scoop bucket add java && scoop install openjdk21
scoop bucket add scoop-clojure && scoop install clojure
scoop install babashka
----

== Verify installation

[source,bash]
----
java -version
clojure -Sdescribe
bb --version
----

== Using individual libraries

Wagoe libraries are published to Clojars. Add only what you need:

[source,clojure]
----
;; Validation utilities only
{:deps {com.wagoe/wagoe-core {:mvn/version "1.1.2"}}}

;; Full web application stack
{:deps {com.wagoe/wagoe-platform {:mvn/version "1.1.2"}
        com.wagoe/wagoe-user     {:mvn/version "1.1.2"}
        com.wagoe/wagoe-admin    {:mvn/version "1.1.2"}}}
----

See xref:libraries:index.adoc[Library Overview] for the complete list of available libraries.
