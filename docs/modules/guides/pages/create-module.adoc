= Create a Module
:description: How to scaffold and integrate a new Wagoe module.

The scaffolder generates a complete FC/IS module quickly.

== Interactive wizard (recommended)

[source,bash]
----
bb scaffold generate
----

The wizard walks you through:

1. Module name (e.g. `product`)
2. Entity name (e.g. `Product`)
3. Fields with types and constraints
4. Shows a summary and the equivalent raw command
5. Runs the generator

== Non-interactive

[source,bash]
----
bb scaffold generate \
  --module-name product \
  --entity Product \
  --field name:string:required \
  --field sku:string:required:unique \
  --field price:decimal:required \
  --field description:string

# Preview without writing
bb scaffold generate --dry-run \
  --module-name product \
  --entity Product \
  --field name:string:required
----

== AI-assisted scaffolding

[source,bash]
----
# Interactive confirm
bb scaffold ai "product module with name, price, and stock quantity"

# Non-interactive
bb scaffold ai "product module with name, price, and stock quantity" --yes
----

== What gets generated

For a `product` module, the scaffolder creates:

* 9 source files: schema, ports, core (`product`, `ui`), shell (service, persistence,
  http, web_handlers, module_wiring)
* 3 test files: core unit, repository, service
* An up and a down migration
* A commented seed example in `resources/seeds/dev.edn`

`--no-http` and `--no-web` leave out the API routes or the web UI.

== Integration steps

After scaffolding:

[source,bash]
----
# 1. Write :wagoe/product into every resources/conf/<profile>/config.edn
bb scaffold integrate product

# 2. Apply the migration
clojure -M:migrate up

# 3. Reload the system
# In REPL: (reset)
----

The config key is the whole registration: the module's routes come from its
`module_wiring.clj`.

== Adding fields after the fact

[source,bash]
----
bb scaffold field  # Interactive: choose module, field name/type
----

This writes an `ALTER TABLE` migration and adds the field to `schema.clj`.

== Other scaffold commands

[source,bash]
----
bb scaffold entity      # Add an entity to an existing module
bb scaffold endpoint    # Add an endpoint to an existing module
bb scaffold adapter     # Generate a new adapter implementation
bb scaffold subscriber  # Add an event subscriber to a module
bb scaffold             # Show all commands and help
----

To create a *new project* (rather than a module inside this one), use the Wagoe
CLI: `wagoe new my-app`.

See xref:libraries:scaffolder.adoc[Scaffolder library] for the full reference.
