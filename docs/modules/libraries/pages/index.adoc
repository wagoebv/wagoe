= Library Overview
:description: All 30 independently publishable Wagoe libraries, application and tooling alike.

Wagoe is a monorepo of 30 libraries published to Clojars under the `com.wagoe`
group.
Every library follows the same FC/IS structure, making the codebase instantly familiar across libraries.

== Foundation

[cols="1,3",options="header"]
|===
| Library | Purpose

| xref:core.adoc[core]
| Foundation: validation framework, case/type conversion utilities, interceptor pipeline, feature flags. No shell layer — entirely pure functions.

| xref:observability.adoc[observability]
| Cross-cutting observability: structured logging, metrics, tracing breadcrumbs, and pluggable error reporters (Datadog, Sentry).

| xref:platform.adoc[platform]
| HTTP routing/interceptors, database integration, CLI/runtime wiring. Infrastructure for feature libraries.

| xref:ui-style.adoc[ui-style]
| Shared UI contract: centralized CSS/JS bundles, tokens, and reusable style conventions across libraries.

| xref:shared-ui.adoc[shared-ui]
| Shared Hiccup primitives: form controls, tables, layouts, modals, icons. Pure functions, no ports — extracted to dissolve the admin↔user dependency cycle.

| xref:i18n.adoc[i18n]
| Internationalisation: marker-based translation, locale chain resolution, EDN catalogues, Ring middleware, and Babashka tooling.
|===

== Application

[cols="1,3",options="header"]
|===
| Library | Purpose

| xref:user.adoc[user]
| Authentication, authorization, MFA (TOTP), session management, JWT tokens.

| xref:admin.adoc[admin]
| Auto-generated CRUD admin UI from schema. Hiccup + HTMX, no frontend build step.

| xref:storage.adoc[storage]
| File storage: local filesystem and AWS S3 / S3-compatible backends.

| xref:scaffolder.adoc[scaffolder]
| Interactive module code generator. Generates FC/IS modules with tests and migrations.

| xref:cache.adoc[cache]
| Distributed caching with TTL, atomic operations, and multi-tenant isolation. Redis and in-memory backends.

| xref:events.adoc[events]
| Asynchronous event bus for cross-process module communication. Redis Streams and in-memory, at-least-once delivery with consumer groups.

| xref:jobs.adoc[jobs]
| Background job processing with priority queues, retries, exponential backoff, multi-tenant support.

| xref:email.adoc[email]
| Email sending: SMTP, async, and queued via jobs integration.

| xref:tenant.adoc[tenant]
| Multi-tenancy with PostgreSQL schema-per-tenant isolation. Requires PostgreSQL.

| xref:realtime.adoc[realtime]
| WebSocket real-time communication, JWT auth, topic-based pub/sub.
|===

== Extensions

[cols="1,3",options="header"]
|===
| Library | Purpose

| xref:external.adoc[external]
| External service adapters: Twilio SMS/WhatsApp, SMTP/IMAP.

| xref:payments.adoc[payments]
| Payment provider abstraction: Stripe, Mollie, and Mock adapters with checkout-session flow and webhook verification.

| xref:workflow.adoc[workflow]
| Declarative state machine workflows with permission-based transitions and audit trail.

| xref:search.adoc[search]
| Full-text search: PostgreSQL FTS with LIKE fallback for H2/SQLite.

| xref:reports.adoc[reports]
| PDF, Excel (XLSX), and Word (DOCX) generation via `defreport` macro.

| xref:calendar.adoc[calendar]
| Recurring events, RRULE recurrence (DST-aware), iCal export/import, conflict detection.

| xref:geo.adoc[geo]
| Geocoding (OSM/Google/Mapbox), DB-backed cache, rate limiting, Haversine distance.

| xref:audience.adoc[audience]
| Rule-based audience segmentation: `defaudience` macro, hybrid SQL + predicate evaluation, AND/OR/NOT composition, cached membership.

| xref:push.adoc[push]
| Mobile push notifications via FCM and APNs: `defpush` macro, device token lifecycle, job-backed reliable delivery, delivery analytics.

| xref:ai.adoc[ai]
| Framework-aware AI tooling: NL scaffolding, error explainer, test generator, SQL copilot, docs wizard.
|===

== Developer Tooling

These are published to Clojars like the rest — they are listed separately
because you reach for them at development time rather than depending on them
from application code.

[cols="1,3",options="header"]
|===
| Library | Purpose

| xref:devtools.adoc[devtools]
| Dev-only: error pipeline (BND codes), dev dashboard (localhost:9999), REPL power tools, guidance engine, request recording, AI REPL commands.

| xref:tools.adoc[tools]
| Dev-only: deploy to Clojars, config doctor, setup wizard, scaffolder integration, quality checks, i18n management.

| xref:cli.adoc[wagoe-cli]
| The `wagoe` command: `wagoe new` to create a project, `wagoe add` to wire in an optional module, `wagoe list modules`.

| xref:mcp.adoc[wagoe-mcp]
| MCP server over stdio: exposes the framework's tools and resources to editor agents via JSON-RPC.
|===

== Clojars coordinates

All libraries share the `com.wagoe` group:

[source,clojure]
----
{com.wagoe/wagoe-core      {:mvn/version "1.0.0-beta-4"}
 com.wagoe/wagoe-user      {:mvn/version "1.0.0-beta-4"}
 com.wagoe/wagoe-admin     {:mvn/version "1.0.0-beta-4"}
 com.wagoe/wagoe-platform  {:mvn/version "1.0.0-beta-4"}
 ;; etc.
 }
----
