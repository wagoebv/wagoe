= external
:description: External service adapters: Twilio, SMTP, IMAP, and FTPS.

External third-party service adapters following the FC/IS pattern.
Four adapters: SMTP, IMAP, Twilio, and an FTPS file source.

NOTE: Stripe payments have moved to xref:payments.adoc[payments] library.

== Key namespaces

[source]
----
wagoe.external.schema              — Malli schemas for all three adapters
wagoe.external.ports               — Protocols: ISmtpProvider, IImapMailbox,
                                        ITwilioMessaging
wagoe.external.core.smtp           — Pure SMTP helpers
wagoe.external.core.imap           — Pure IMAP helpers
wagoe.external.core.twilio         — Pure Twilio helpers (build SMS/WhatsApp params)
wagoe.external.shell.adapters.smtp — SmtpProviderAdapter (javax.mail)
wagoe.external.shell.adapters.imap — ImapMailboxAdapter (javax.mail, UIDFolder)
wagoe.external.shell.adapters.twilio  — TwilioAdapter (clj-http, Basic auth)
wagoe.external.shell.adapters.ftps — FtpsFileSource (Commons Net, explicit TLS)
----

== Enabling adapters

All four adapters ship as `:inactive` in `config.edn`. Move to `:active` to enable:

[source,clojure]
----
;; In :active section of resources/conf/dev/config.edn

:wagoe.external/twilio
{:account-sid #env TWILIO_ACCOUNT_SID
 :auth-token  #env TWILIO_AUTH_TOKEN
 :from-number #env TWILIO_FROM_NUMBER}

:wagoe.external/smtp
{:host     #env SMTP_HOST
 :port     587
 :username #env SMTP_USERNAME
 :password #env SMTP_PASSWORD
 :tls?     true}

:wagoe.external/imap
{:host     #env IMAP_HOST
 :port     993
 :username #env IMAP_USERNAME
 :password #env IMAP_PASSWORD
 :ssl?     true}

:wagoe.external/ftps
{:host     #env FTPS_HOST
 :username #env FTPS_USERNAME
 :password #env FTPS_PASSWORD}
----

== Twilio SMS / WhatsApp

[source,clojure]
----
(require '[wagoe.external.ports :as ports])

;; Send SMS
(ports/send-sms twilio {:to "+31612345678" :body "Your code: 123456"})

;; Send WhatsApp
(ports/send-whatsapp twilio {:to "+31612345678" :body "Your order has shipped!"})
----

== FTPS file imports

`IFileSource` lists a directory and downloads files. The connection uses explicit
TLS with an encrypted data channel, passive mode and binary transfers, and the
server certificate is checked against the JVM's trust store, or `:trust-store`.

[source,clojure]
----
(ports/list-files! ftps "/outbox" {:match #"contacts-.*\.csv" :skip already-imported})
;; => {:success? true :files [{:name "contacts-1.csv" :path "/outbox/contacts-1.csv" :size 812 ...}]}

(ports/fetch-file! ftps "/outbox/contacts-1.csv")
;; => {:success? true :content <bytes> :size 812 :path "/outbox/contacts-1.csv"}
----

Transient failures (DNS, refused connection, timeouts, 4xx replies) are retried
with backoff, `:max-attempts` times in all. A 5xx reply such as a rejected login
fails at once. A failure returns `{:success? false :error {:type :external-error ...}}`,
with `:host`, `:attempts` and `:cause`.
