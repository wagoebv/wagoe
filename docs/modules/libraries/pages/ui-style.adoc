= ui-style
:description: Shared UI styling contract and asset bundles for Wagoe modules.

The `ui-style` library centralizes app-wide UI assets and conventions:

* CSS bundles (`:pilot`, the default, and `:admin-pilot`)
* JavaScript bundles (`:pilot`, `:admin-pilot`)
* Shared design tokens and reusable UI primitives

It prevents per-library style drift by making layout namespaces consume the same bundle API.

== Coordinates

[source,clojure]
----
{:deps {com.wagoe/wagoe-ui-style {:mvn/version "1.1.0"}}}
----

== API

Namespace: `wagoe.ui-style`

* `pilot-css`, `admin-pilot-css`
* `pilot-js`, `admin-pilot-js`
* `(bundle k)` for CSS bundle selection. An unknown key, including the removed
  `:base`, warns once and gets `:pilot`
* `(js-bundle k)` for JS bundle selection

For implementation details and migration notes, see `libs/ui-style/README.md` in the repository.
